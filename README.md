# Guandan Webgame

一个可直接运行的四人掼蛋单机 Web 游戏。

> 当前版本：**v0.2.0**（2026-07-23）。AI 牌型、逢人配、音频和移动端体验已全面升级，详见 [版本公告](CHANGELOG.md)。

## 运行

无需构建和安装依赖，在项目目录启动任意静态服务器：

```bash
npm start
```

然后访问 <http://localhost:4173>。

规则引擎测试：`npm test`。

## 当前功能

- 两副牌、四人两队、每人 27 张牌
- 单张、对子、三张、三带二、顺子、三连对、钢板、同花顺和炸弹判定
- 红桃级牌“逢人配”
- 三位具备队友协作的本地 AI、完整牌型提示、过牌、轮次重置和完赛排名
- 根据头游/队友名次连升 1–3 级，可连续进行多局比赛
- 独立音效与程序化背景音乐控制
- 键盘操作、读屏状态、减少动画和桌面/移动端自适应界面

当前版本定位为可连续对局的单机练习版。进贡还贡、正式升级计分和多人联机仍待后续规则设计。
