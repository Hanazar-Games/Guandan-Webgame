# Guandan Webgame

一个可直接运行的四人掼蛋单机与局域网 Web 游戏。

> 当前版本：**v0.9.1**（2026-07-28）。本次修正双下结算与 AI 炸弹选择，并完善设置极值布局、公告重排和键盘可访问性，详见 [版本公告](CHANGELOG.md)。

## 运行

无需安装依赖，在项目目录启动内置服务：

```bash
npm start
```

然后访问 <http://localhost:4173>。

同一局域网内的其他设备打开主页面“局域网联机”显示的地址，再通过六位房间码加入。房间支持 2–4 名真人，空座由 AI 补齐。

规则引擎测试：`npm test`。

## 当前功能

- 两副牌、四人两队、每人 27 张牌
- 单张、对子、三张、三带二、顺子、三连对、钢板、同花顺和炸弹判定
- 红桃级牌“逢人配”
- 三位具备队友协作的本地 AI、完整牌型提示、过牌、接风、轮次重置和完赛排名
- 双下立即结算，根据头游/队友名次连升 1–3 级，可连续进行多局比赛
- 房主规则校验的局域网房间、2–4 名真人与 AI 补位
- 主页面、公告、五步新手教程、关于与完整设置中心
- 10 种界面语言，独立 SFX/BGM 音量、音高、音色、速度与音乐层次调节
- 可调动画、牌面、亮度、对比度、饱和度、手牌重叠、选牌抬升与提示时长
- 可调 AI 思考时间、提示自动定位、重开确认、震动强度与一键恢复默认
- 键盘操作、读屏状态、减少动画和桌面/移动端自适应界面

当前版本定位为可连续对局的练习版。进贡还贡、正式升级计分和互联网匹配仍待后续规则设计。
